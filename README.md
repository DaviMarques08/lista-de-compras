# Lista de Compras Inteligente

Uma aplicação simples e funcional para gerenciar listas de mercado, permitindo adicionar itens e salvar o progresso.

## 🚀 Tecnologias Utilizadas
* HTML5
* CSS3
* JavaScript (Vanilla)
* Conceitos de PWA (Service Workers e Manifest)

## 📌 Funcionalidades
* Adicionar itens à lista
* Salvar a lista localmente
* Funciona offline (PWA)
